# Oslo Whiskyfestival 2026 – barer & smakeliste

PWA med alle barer og whiskyer fra festivalhåndboka. Marker det du vil smake, gi rating, legg til Whiskybase-lenker og del lista via lenke. Alt lagres lokalt i nettleseren.

```sh
npm install
npm run dev
```

Publiseres automatisk til GitHub Pages ved push til `main` (se `.github/workflows/deploy.yml`).
